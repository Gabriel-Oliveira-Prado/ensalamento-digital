# Como contribuir

1. Atualize sua cópia da `main`.
2. Crie uma branch para cada tarefa, por exemplo `feature/tela-de-salas` ou `fix/correcao-de-login`. Quem não tem acesso de escrita pode criar um fork e trabalhar em uma branch do fork.
3. Faça commits nessa branch e abra um pull request para `main`. Descreva o que mudou e como verificou a alteração.
4. Aguarde as verificações automáticas e a aprovação de um dos responsáveis definidos em `.github/CODEOWNERS`.
5. Depois que o pull request for mesclado, apague a branch de trabalho.

Não envie commits diretamente para `main`. A proteção da branch exige pull request e aprovação de um responsável pelo código.
